What you get

Built for people who actually download things

Blazing-Fast Downloads

Powered by yt-dlp — the fastest, most feature-complete video downloader around, covering thousands of sites out of the box.

Live Stream Capture

Capture live broadcasts in real time with ffmpeg baked in. Never miss a stream because you were busy setting up tools.

Smart Playlist Detection

Drop a link and StreamDock figures out if it's a single video, a full playlist, or an episode range — then lets you pick exactly what you want.

Dub / Sub / Server Labels

Every audio and subtitle option is clearly labeled by language before you download — no more guessing between "Stream 2" and "Stream 3".

Real Titles, Tidy Folders

Files keep the title the source gave them — no invented episode numbering. A playlist gets one folder; a single video is never buried in one.

Dynamic Wallpaper System

Set your workspace to Bing's daily wallpaper on a refresh schedule, or pick a custom color from the full palette picker. Saved across launches.

Plugin System

Ships with community yt-dlp extractors for sites the stock engine can’t reach — anime sources, cookie unlocking and token providers, already wired in.

Responsive, Sandboxed UI

A clean React interface that adapts to any window size, built on Electron security best practices with every IPC boundary typed and validated.
